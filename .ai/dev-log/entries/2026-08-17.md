# 2026-08-17

Cilj dana: Iz predloga za nadogradnju (NADOGRADNJE/ + MGP/) izgraditi AI slojeve i ožičati postojeći monitoring, sve osim OpenRouter (koji ide uz CODIUM).

Urađeno:
- Zapisana dva razmatranja: `.ai/razmatranje/ai-modeli-registar-i-rutiranje.md` (koncept registra/rutiranja) i `.ai/razmatranje/ai-i-monitoring-implementacija-plan.md` (izvršni plan, faze A–E).
- Zatečeno: `file_monitor`, `auto_import`, `kalima/security` + testovi već postoje (od disk-skener sesije); nedostajalo je samo ožičavanje (API/boot/GUI).
- **Faza A — Monitoring ožičavanje**: `auto_import_runtime` + `kalima_runtime`; routeri `filmium_auto_import` (folders/detected/confirm/reject) i `kalima_security` (scan/quarantine); autostart praćenja perzistiranih foldera u `core_lifespan` (+`AutoImportService.resume_persisted`); KALIMA→FILMIUM `SecurityStatus` adapter. GUI: `FilmiumAutoImportPanel` + hook + api + tipovi + CSS, montiran u Uploads sidebar.
- **Faza B — CORE AI**: `core/ai/` — `ModelRegistry` (`config/models_config.json`, fallback na default-e), `OllamaClient` (urllib, lenj, injektabilan transport, `OllamaUnavailable`), `CoreRouter` (tekst/putanja → validan JSON intent, fallback pri padu). API `GET /core/models`, `POST /core/route`.
- **Faza C — FILMIUM Kurator (RAG)**: `MediaRetriever` (lokalni skor nad postojećom bazom, bez ChromaDB) + `CuratorService` (top-N kontekst → qwen2.5 → odgovor na srpskom, fallback lista naslova). API `POST /filmium/curator/ask`.
- **Faza D — Whisper STT**: `VramGuard` (mutex „jedan model u VRAM-u"), `WhisperService` (strogo load→transcribe→unload, VRAM oslobođen i na grešci, lenj `whisper`/`torch` import). API `POST /core/stt/transcribe` (503 kad nedostupan, 409 kad VRAM zauzet).
- **Faza E — SICA osnova**: `telemetry.FailureEvent` + `SicaLoop` (predlog patcha → sandbox grana → ceo test-run → merge SAMO ako 100% prođe, inače odbaci; sve injektabilno: git/runner/LLM/devlog). Bezbedan skelet, ne pun autonomni sistem.
- Verifikacija: **868 pytest** (bilo 829, +39 novih), **332 vitest**, `tsc --noEmit` čist. Nula regresija.

Sledeće:
- GUI za Kurator (chat panel) i glas (push-to-talk okidač) — backend gotov.
- Pravi importer u `auto_import.confirm_import` (single-file → biblioteka; sada `importer=None`, samo označava IMPORTED).
- OpenRouter konektor + Sanitizer (maskiranje/demaskiranje) — uz CODIUM.
- Provezati SICA sa pravim git/pytest adapterima kad se krene autonomija.

Napomene/odluke:
- `models_config.json` živi u korenskom `config/` (=`core_paths.config`); promena `provider` preusmerava saobraćaj bez menjanja domenske logike.
- Svi AI pozivi degradiraju uredno kad Ollama/Whisper nisu prisutni (nema pada API-ja) — bez novih teških zavisnosti (urllib; whisper/torch lenjo i opciono).
- OpenRouter svesno van obima ove sesije.

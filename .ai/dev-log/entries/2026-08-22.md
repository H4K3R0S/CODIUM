# 2026-08-22

Cilj: Profesionalniji CODIUM izgled — ujedinjen sidebar po CORE pravilu, nov Overview dashboard, i pomerljiv/sklopiv AI chat okvir koji u workspace-u deli donji prostor sa terminalom.

## Urađeno

### Sidebar (zajednički CORE shell)
- Utvrđeno i zapisano univerzalno pravilo: postoji JEDAN CORE sidebar za sve domene. Zaključano za CORE: gornji ikonski red (5 slotova) + prvi separator, i donji „CORE Online" status + separator iznad njega. Srednji pojas (između ta dva separatora) je domenski — svaki domen ga puni svojim opcijama i sme ga blago stilizovati, ali ne dira zaključane delove. (Zapisano i u agentovu memoriju: core-sidebar-shared-shell.)
- CODIUM srednji pojas prepravljen prema mockup-u: 3 sekcije — CODIUM (Overview, Projects, Repositories, AI Workspace, Tasks, Pipelines, Deployments, Infrastructure, Monitoring, Analytics), AI & AUTOMATION (AI Agents, Automations, Integrations), SYSTEM (Settings, Access & Users, Audit Logs). Ožičeno realno: Overview→/codium, Projects→/codium/projects, AI Workspace→workspace aktivnog projekta, Tasks→tasks panel, Settings→/settings; ostalo „USKORO" dijalog. Data-driven render (CodiumNavItem).
- Smireniji stil (scoped .codium-nav-section): hover = blaga akcent-tint + leva akcent-crta; aktivno = akcent-tint 0.14 + puna leva žuta crta, bez neon gradijenta/glowa. AI Workspace pokazuje aktivno dok si u workspace-u.

### CODIUM Overview dashboard (/codium)
- Nov CodiumOverview.tsx: /codium sada je dashboard, a mreža projekata (stari hub CodiumPage) preseljena na /codium/projects.
- 6 stat kartica — realni podaci gde postoje (Active Projects, Repositories = projekti sa repo URL, Tasks iz getTasks), a Pipelines/Deployments/Code Quality označeni „mock".
- Kolone: Active Projects (realni aktivni projekti, progres = završeni/ukupno taskova, klik → workspace), Live Activity (mock), AI Agents (mock). Bez „System Health" trake (po zahtevu).
- codium-dashboard.css — smiren „enterprise" ton (token set surface/border/text-muted), akcent tačkasto. Doterivanje rasporeda: jednake kolone (minmax(0,...)), jednaka visina panela (align stretch), veći razmaci, oštre ivice (radius 0).

### Chat okvir (CoreChat + CODIUM)
- CoreChat dobio `suggestions` prop → predlog-kartice u praznom stanju; klik šalje prompt. CODIUM hub chat nosi 4 kartice: Napravi/Analiziraj/Debaguj/Deploy projekat.
- CodiumHubChat pomerljiv: položaj dole (donji-centar) ↔ desni panel (pamti se u codium.chat.pos). Dole: telo se sklapa u traku (animacija visine). Desno: klizne u/iz ekrana (animacija transform); minimizovan = vertikalna ikona-tab uz desnu ivicu (klik otvara), sa dugmetom za minimiziranje u zaglavlju. Oštre ivice unutar chata (scoped na .chub, ne dira CORE chat drugde).

### Workspace — ujedinjeni AI okvir + terminal
- AI Workspace koristi isti okvir (položaj/minimize/tab) kao dashboard, ali unutra ostaje postojeći AiAssistant sadržaj (deli codium.chat.pos).
- Donji režim (fiksni raspored): jedan zajednički donji okvir — terminal levo, asistent desno. Bez debelog zaglavlja/naslova; ikonica za prelaz u desni panel stoji u okviru chata (gore-desno). Prelaz „desno" odmah otvara pun desni panel (ne tab).
- Sklapanje donjeg okvira: dvoklik samo po „naslovnim" zonama — gornja ivica (resizer; prevlačenje=visina, dvoklik=sakrij), prazan deo tab-trake terminala (.cterm-tabbar), i zaglavlje asistenta (.cai-head). Sadržaj terminala/chata slobodan za normalan dvoklik.
- Potpuno sklopljeno = tanja traka (~22px) za vraćanje. Desni režim: bočna kolona (dole/odvoji/minimizuj) ili ikona-tab kad je minimizovan.

#### npm zavisnosti u registru alata (`2bf59cb`)

Uzrok zašto se Monaco i xterm nisu videli: `check_dependency` je za sve što nije
Python radio `shutil.which(probe)`, tj. tražio izvršni fajl na PATH-u. npm paket
je folder u `node_modules`, pa se nije mogao registrovati — uvek bi pisao da
nedostaje.

- `DependencyKind.NPM` + `DependencyInstaller.NPM`.
- `npm_package_installed(package, gui_root=None)` — proverava
  `apps/gui/node_modules/<paket>/package.json`. Scoped imena rade bez posebnog
  slučaja.
- Registrovano šest GUI alata: `monaco-editor`, `@monaco-editor/react`,
  `@xterm/xterm`, `@xterm/addon-fit`, `@xterm/addon-search`, `dockview-react`.
- `scripts/install/npm_install.ps1` — `npm install` **bez argumenta** u
  `apps/gui`. Usklađuje `node_modules` sa `package.json`, poštuje lock, ne menja
  verzije. Ime paketa nigde ne putuje kao argument.
- GUI: `dependencyTabs.ts` (čist modul) + traka tabova `Sve / Hitno / Važno /
  Opciono` sa brojem onoga što nedostaje; neinstalirano ide na vrh liste.
- `docs/DEPENDENCIES.md` dopunjen katalogom i odeljkom o npm zavisnostima.

Provereno uživo: `/api/v1/system/dependencies` vraća 17 alata, svih šest npm
prijavljuje `installed: true`; panel u GUI-ju prikazuje tabove i filtrira
(tab „Opciono" → VLC, mpv, `@xterm/addon-search`).

Testovi: 1000 pytest, 527 vitest, `tsc` čist.
